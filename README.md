# Student Feedback Management System

A cloud-based student feedback application built using AWS.

## Technologies
- HTML, CSS, JavaScript
- Amazon S3
- Amazon API Gateway
- AWS Lambda (Python 3.12)
- Amazon DynamoDB
- AWS IAM

## Architecture
Student → S3 Website → API Gateway → Lambda → DynamoDB

## Features
- Student feedback submission
- API-based backend processing
- Feedback storage in DynamoDB
- Serverless AWS architecture

## AWS Resources
- DynamoDB Table: StudentFeedback
- Lambda: student-feedback-api
- API: StudentFeedbackAPI
- S3 Website: aws-devops-cicd-juneed-2026
